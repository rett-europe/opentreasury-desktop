Dot styling — 3 alternatives

Same data, same labels, same bars. Only the row's category-color affordance changes. Sample uses 5 expense subcategories from 5 different donut categories.

A. Current — 10px filled circle, inline

Tiny dot floats next to the label. No dedicated column, easy to miss, color reads as "ink speck" rather than category swatch.

B. Outlined ring — 12px hollow circle

Open ring (2px stroke) reads as a deliberate marker, not a smudge. Slightly larger so the color band is legible. Works on any background.

C. Vertical color stripe — 4px on row's left edge

Drops the dot entirely. A 4px tall stripe attaches the color to the whole row, like a Kanban-card accent. Tightly couples to the bar's color, removes the "extra speck" problem.
