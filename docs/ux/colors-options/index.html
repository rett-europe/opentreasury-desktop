Palette 1 — Wide-hue OKLCH (45° spacing, alternating L)

Same OKLCH model, but hues spread to 45° apart and lightness alternates (0.62 / 0.68 / 0.70 / 0.78 …) so adjacent slices differ in both hue AND luminance — survives deuteranopia and small-dot rendering. Still works on either side (gastos/ingresos) since donut is category-mixed not gastos-vs-ingresos.
