# Morpheus — Runtime Crash Hotfix: Drop `ulid` for Node `crypto.randomUUID()`

## Problem

**Symptom:** Electron main process crashed on boot with:
```
Error: secure crypto unusable, insecure Math.random not allowed
```

**Root Cause:** The `ulid` npm package's `detectPrng()` function relies on `globalThis.crypto.getRandomValues()`. After esbuild ESM bundling, the bundled code lost access to this global, causing the error. The package cannot fall back to `Math.random()` in strict mode.

## Solution

**Swap to Node built-in:** Replaced `ulid` calls with `crypto.randomUUID()` from the `node:crypto` module, which:
- Is built into Node.js (no detection needed)
- Produces cryptographically-secure 128-bit UUIDs (equally opaque as ULIDs)
- Requires zero PRNG detection or fallback logic

**Why safe:** Session file IDs are used as opaque tokens only (not for sortability or lexicographic ordering). UUID v4 is a drop-in replacement.
