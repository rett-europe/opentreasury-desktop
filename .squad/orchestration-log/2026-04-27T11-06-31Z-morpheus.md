## Scope

Implemented 5 label-detail IPC channels for insights drilldown:
- `insights:label-summary` (header KPIs: income, expense, net, txCount, categories, accounts)
- `insights:label-by-category` (donut data, sorted by magnitude)
- `insights:label-by-subcategory` (table rows, split-aware)
- `insights:label-monthly-evolution` (sparkline buckets, sparse monthly)
- `insights:label-by-account` (horizontal bar data, account color support)

All channels share `LabelDetailRequest` contract:
```ts
{ tagIds: string[], windowStart?: ISO, windowEnd?: ISO, accountId?: string }
```

## Locked Semantics

1. **OR across tagIds** — drilldown shows union of selected campaigns
2. **Single-count per aggregate** — transaction with multiple matching tags counted once
3. **Split-aware via `effectiveAmounts`** — splits expand parent tx into N rows per subcategory
4. **Default window = current calendar year**, end capped at today
5. **Archived accounts excluded** — parity with landing summary
