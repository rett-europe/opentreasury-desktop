### Iter 8: Header alignment root cause (Trinity, 2026-04-27)
**Commit:** c6c8646

Re-diagnosed using screenshot evidence + DevTools Grid inspector:
- Header and rows are SEPARATE grid containers, each computing `1fr` independently.
- Header had `font-size: var(--font-size-11)` on the container; rows inherited larger font-size (~16px).
- `ch`-based column minimums resolve relative to grid container's font-size → different minimums → `1fr` distribution differs → columns drift.

**Root cause:** font-size belonged on grid children, not containers.

**Fix:** Moved font-size/letter-spacing/text-transform from `.ot-saldo-panel__columns` to its children; rows already inherited correctly. Also reduced double `+ var(--space-6)` to single, added `minmax(0,1fr)` to outer panel grid + `min-width:0` on panels for shrinking.

Result: Header aligned. Panels overflow at narrow viewports (Bug B).

## Learnings Earned

1. **Visual bug diagnosis is not code analysis** — screenshot + DevTools inspector mandatory before writing specs.
2. **Grid container properties affect unit resolution** — `ch` is relative to the grid container's font-size, not cell font-sizes.
3. **Responsive shrinking in grids requires layered constraints:**
   - Outer grid: `minmax(0, 1fr)` for flex allocation
   - Inner containers: `min-width: 0` to allow shrink
   - Track minimums: `min-content` for critical content (amounts), `0` for truncatable content (names)
   - Media query: override `fr` ratios at viewport breakpoints
4. **Amounts are the last line of defence** — use `min-content` minimums to guarantee readability at any width.
