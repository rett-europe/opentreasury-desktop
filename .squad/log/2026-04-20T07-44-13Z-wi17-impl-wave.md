## Key Decisions

### Library Swap: xlsx → exceljs
- **Why:** xlsx has CVE-2023-30533 (prototype pollution) + CVE-2024-22363 (ReDoS), no npm fix
- **Trade-off:** +400KB bundle, ~20% slower, but actively maintained + zero HIGH CVEs
- **Result:** npm audit clean (was 1 HIGH before)

### Security Architecture: Opaque FileId Tokens
- **Pattern:** Renderer stage-file once → main returns opaque ULID → renderer passes ULID to dry-run/commit
- **Benefit:** Mitigates path-traversal in compromised renderer; main validates token against session allowlist
- **TTL:** 30 min per file, auto-evict after commit

### TS Strict Mode: exactOptionalPropertyTypes
- **Learning:** Optional props must explicitly allow `undefined` in type signature, not just `?:` shorthand
- **Applied to:** ConfiguracionScreen.tsx DatosTab integration
